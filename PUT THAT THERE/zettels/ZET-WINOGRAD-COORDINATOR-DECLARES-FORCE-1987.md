ZET-WINOGRAD-COORDINATOR-DECLARES-FORCE-1987

TITLE:
The Coordinator Makes Conversational Force Explicit Before the Message Proceeds

SOURCE:
Terry Winograd - “A Language/Action Perspective on the Design of Cooperative Work” - 1987. ([LRI](https://www.lri.fr/~mbl/ENS/CSCW/2016/papers/Winograd-HCI87.pdf))

PASSAGE:
The Coordinator presents distinct openings such as Request and Offer, with templates that structure the subsequent conversation.

RESEARCH OBJECT:
The difference between classifying language action in advance and allowing its force to stabilize through interaction.

LOCAL MOVE:
Corrects the idea that The Coordinator resembles contemporary LLM intent inference. It makes users enter an explicit communicative-action ontology.

SOURCE TERMS:
Request; Offer; conversation for action; commitments; language/action perspective; templates.

WHAT BECAME STRANGE:
A theory intended to treat language as action becomes a GUI in which the user must classify the action before fully performing it.

QUESTION:
What conversational flexibility is gained or lost by declaring illocutionary force before the utterance?

DEEPER QUESTION:
Could generative interfaces reopen the ambiguity that workflow systems had to eliminate in order to compute coordination?

MECHANISM:
The interface constrains possible conversational trajectories by requiring selection among predefined action categories.

FORMAL SHIFT:
LANGUAGE AS EMERGENT COORDINATION → LANGUAGE ACTION AS DECLARED WORKFLOW STATE.

SOURCE FORMALISM:
The Coordinator structures communication around action categories and expected responses.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
UTTERANCE = FORCE_ENUM + CONTENT + COMMITMENT_STATE.

TENSION:
The language/action perspective was explicitly anti-information-transfer in orientation, yet implementation may harden its action categories.

MISSING:
Winograd’s 1994 response to Suchman and the degree to which later Language/Action work relaxed these categories.

BOUNDARY:
Do not reduce the whole Winograd/Flores project to one software product.

CITATION TRAIL:
Maturana → Winograd/Flores → Coordinator → Suchman 1994.

TEST:
Compare a task in two interfaces: one requires REQUEST/OFFER/PROMISE selection before text; one allows free-form interaction and infers/negotiates force after response.

PLATFORM:
CSCW / language-action HCI.
