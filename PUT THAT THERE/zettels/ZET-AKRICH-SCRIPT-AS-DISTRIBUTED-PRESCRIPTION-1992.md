TITLE:
Technical Objects Allocate Roles and Actions Through Scripts

SOURCE:
Madeleine Akrich - “The De-Scription of Technical Objects” - 1992. ([ResearchGate](https://www.researchgate.net/publication/242461431_The_De-scription_of_Technical_Objects))

PASSAGE:
[QUOTE]
"Technical objects define a framework of action. Like a film script, technical objects define actors, endow them with specific competencies and motives, and prescribe a distribution of roles between human and non-human entities... In order to understand technical objects, we must de-scribe them—read the script back out of the artifact." — Madeleine Akrich, The De-Scription of Technical Objects, MIT Press, pp. 205–208 (1992)

RESEARCH OBJECT:
The artifact as a model for its own user.

LOCAL MOVE:
Strengthens the claim that an interface does not merely communicate with an implied user; it materially distributes roles, competencies, permissions, and expected actions.

SOURCE TERMS:
de-scription; technical object; script; actor; network; user; relation.

WHAT BECAME STRANGE:
The interface can be read in two directions: from imagined users into design inscriptions, and from those inscriptions back into the conduct expected of actual users.

QUESTION:
Which elements of a Yellow Circle interface are descriptive representations of expected use, and which actively enforce that expected use?

DEEPER QUESTION:
When a prompt interface allows open natural language, has the technical script weakened, or migrated into model inference?

MECHANISM:
Design decisions inscribe distributions of agency and competence that become consequential when actors interact with the artifact.

FORMAL SHIFT:
PERSONA → INTERFACE becomes INTERFACE → ROLE OFFERED/IMPOSED ON USER.

SOURCE FORMALISM:
Akrich’s “de-scription” analyzes how technical objects embody programs of action for heterogeneous actors.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
SCRIPT(interface) =
constraints + invitations + delegated competencies + expected user responses.

TENSION:
Natural-language agents may conceal scripts instead of removing them.

MISSING:

BOUNDARY:
An artifact script does not guarantee actual compliance.

TEST:
