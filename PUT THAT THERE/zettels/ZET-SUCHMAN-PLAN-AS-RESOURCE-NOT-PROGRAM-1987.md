TITLE:
A Plan Can Orient Situated Action Without Determining Its Actual Sequence

SOURCE:
Lucy Suchman - Plans and Situated Actions: The Problem of Human-Machine Communication - 1987. PASSAGE:
[QUOTE]
"Plans are best viewed as a weak resource for what is primarily situated action... Instead of seeing action as the step-by-step execution of a pre-existing plan, we should see action as fundamentally contingent on our embodied, indexical engagement with particular circumstances." — Lucy Suchman, Plans and Situated Actions, Cambridge University Press, pp. 50–52 (1987)

RESEARCH OBJECT:
The status of a prompt as plan, instruction, or situated resource.

LOCAL MOVE:
Opposes a strong operative-description model in which the prompt is treated as a precomputed program whose execution simply unfolds.

SOURCE TERMS:
plans; situated actions; circumstances; human action; communication; interaction; practical action.

WHAT BECAME STRANGE:
A prompt can successfully orient activity even when the eventual action sequence was neither stated nor inferable as a fixed plan beforehand.

QUESTION:
Is a prompt best modeled as a program, a constraint, a plan, a resource, or a move inside ongoing situated action?

DEEPER QUESTION:
What remains of “description becomes operation” if description does not determine the operation but only participates in its situated production?

MECHANISM:
Actors use partial representations together with evolving circumstances and feedback to produce locally appropriate action.

FORMAL SHIFT:
PROMPT → EXECUTION becomes PROMPT + SITUATION + EMERGENT ACTION ↔ FEEDBACK.

SOURCE FORMALISM:
Suchman contrasts plan-centered models with situated accounts of purposeful action.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
NEXT_ACTION_t =
f(prompt, current_world_t, prior_actions, newly_available_resources).

TENSION:
Calling every prompt merely a resource would understate cases where formal descriptions tightly determine execution.

MISSING:
A taxonomy separating executable specification from orienting description in contemporary agents.

BOUNDARY:
Situated action does not imply absence of plans or goals.

CITATION TRAIL:
Suchman 1987 → thick prompting → world-to-world → critique/repair loop.

TEST:
Give agents identical desired outcomes through an exhaustive plan versus a thin goal with observation access; compare path divergence under unexpected environmental perturbations.

PLATFORM:
HCI / situated action.
