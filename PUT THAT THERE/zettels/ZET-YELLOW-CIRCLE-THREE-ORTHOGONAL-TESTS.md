Invariance, Aspect Instability, and Description Displacement Are Three Different Experiments

SOURCE:
Collision: Wittgenstein §§74, Bolt 1980, Ashby 1956. ([Wiley-Blackwell](https://www.blackwellpublishing.com/content/bpl_images/content_store/sample_chapter/9780631231271/Wittgenstein.pdf))

PASSAGE:
Wittgenstein links aspect to different action; Bolt replaces explicit description with situated gesture; Ashby constrains regulation by requisite variety.

RESEARCH OBJECT:
The experimental architecture of the Yellow Circle project.

LOCAL MOVE:
Separates three questions that had begun to blur into one another.

SOURCE TERMS:
aspect; order; pointing; there; requisite variety; regulation.

WHAT BECAME_STRANGE:
NONE

WHAT BECAME STRANGE:
Holding output stable, holding stimulus stable, and holding task stable probe different mechanisms and should not share one score.

QUESTION:
Which experiment should be the primary benchmark and which should be supporting perturbations?

DEEPER QUESTION:
Can these three tests triangulate the location, stability, and migration of operative distinctions?

MECHANISM:
Each test fixes a different variable and perturbs another.

FORMAL SHIFT:
YELLOW CIRCLE AS ONE DEMO → YELLOW CIRCLE AS THREE ORTHOGONAL EXPERIMENTS.

SOURCE FORMALISM:
NONE

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
INVARIANCE: same accepted object, different languages.
ASPECT: same stimulus, different language-game/action-space.
DISPLACEMENT: same task, remove explicit description and locate where requisite distinctions migrate.

TENSION:
The tests can interact; a changed representation may alter both aspect and distribution of description.

MISSING:
Experimental controls that isolate each axis.

BOUNDARY:
Do not infer causal mechanisms from cross-language comparison without controlled perturbations.

CITATION TRAIL:
Wittgenstein §74 + Bolt 1980 + Ashby 1956 → Yellow Circle experimental redesign.

TEST:
Pre-register fixed variables, perturbations, and success criteria separately for all three arms.

PLATFORM:
Experimental methodology.
