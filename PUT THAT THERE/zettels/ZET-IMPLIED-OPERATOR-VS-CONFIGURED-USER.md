ID:
ZET-IMPLIED-OPERATOR-VS-CONFIGURED-USER

TITLE:
Software Has Both a User Role Presupposed by the Artifact and a User Role Produced Through Interaction

SOURCE:
Collision: Wolfgang Iser 1974; Steve Woolgar 1990. ([Google Books](https://books.google.com/books/about/The_Implied_Reader.html?hl=id&id=Ix3uAAAAMAAJ))

PASSAGE:
Iser provides a framework for reader roles structured by texts; Woolgar analyzes usability trials as configuring relations between users and machines.

RESEARCH OBJECT:
Two non-identical senses of “the user inside the software.”

LOCAL MOVE:
Splits a concept that the graph had merged. The implied operator is reconstructed from what the artifact requires; the configured user is produced through sociotechnical practices that teach, discipline, reward, or exclude forms of use.

SOURCE TERMS:
implied reader; reader role; configuring the user; machine as text; usability trial.

WHAT BECAME STRANGE:
The user presupposed by an interface and the user it eventually trains people to become need not be the same.

QUESTION:
How does interaction transform an empirical user toward or away from the artifact’s implied operator?

DEEPER QUESTION:
Can prompt expertise be understood as a process by which users are progressively configured into the model’s implied interlocutor?

MECHANISM:
Artifacts presuppose competencies; repeated success and failure provide feedback that alters users’ behavior toward the repertoire the system rewards.

FORMAL SHIFT:
STATIC IMPLIED USER → DYNAMIC LOOP BETWEEN IMPLIED ROLE AND CONFIGURED PRACTICE.

SOURCE FORMALISM:
Iser and Woolgar offer separate literary and sociological frameworks.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
IMPLIED_OPERATOR = required role encoded by artifact.
CONFIGURED_USER_t = learned participant behavior after interaction history t.

TENSION:
Users also configure systems through customization, correction, appropriation, fine-tuning, and accumulated context.

MISSING:
A reciprocal-configuration account specific to generative interfaces.

BOUNDARY:
Do not infer psychological transformation merely from interface exposure; configuration is sociotechnical, partial, and contestable.

CITATION TRAIL:
Iser 1974 × Woolgar 1990 → prompt superstition → user expertise → languaging.

TEST:
Observe novices learning the Yellow Circle system over repeated trials; measure which initially explicit instructions become omitted and which new conventions users invent.

HCI / STS / reader theory.
