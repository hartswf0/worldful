TITLE:
Human-Machine Communication Fails When the Machine Lacks Access to Resources Humans Use to Make Action Intelligible

SOURCE:
Lucy Suchman - Plans and Situated Actions: The Problem of Human-Machine Communication - 1987. ([Google Books](https://books.google.com/books/about/Plans_and_Situated_Actions.html?id=AJ_eBJtHxmsC))

PASSAGE:
Suchman’s copier study analyzes novice interaction with an “intelligent” machine whose design fails to accommodate resources routinely used in successful human communication.

RESEARCH OBJECT:
Requisite context as asymmetrically available communicative resource.

LOCAL MOVE:
Qualifies thick prompting: information may exist in the situation yet remain useless if one participant lacks access to the resources through which humans normally recover its significance.

SOURCE TERMS:
communicative resources; mutual intelligibility; human-machine communication; inference; occasion; shared understanding.

WHAT BECAME STRANGE:
The problem may not be that the user supplied too little description; the machine may have been built to perceive too little of the situation.

QUESTION:
How much prompt engineering is compensation for impoverished machine access to the interactional world?

DEEPER QUESTION:
Does multimodal AI reduce the description burden primarily by making previously unavailable situated resources machine-readable?

MECHANISM:
Successful human interaction exploits context, sequence, gesture, repair, and practical circumstances that conventional interfaces often exclude from the machine’s perceptual field.

FORMAL SHIFT:
USER MUST EXPLICITATE MORE → SYSTEM CAN PERCEIVE MORE OF THE SITUATION.

SOURCE FORMALISM:
Suchman analyzes asymmetries in communicative resources available to users and interactive machines.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
PROMPT_TAX increases when action-relevant environmental distinctions exist for the human but are outside the machine’s accessible channel.

TENSION:
Greater machine access to context can reduce explicit description while increasing privacy, surveillance, ambiguity, and interpretation risks.

MISSING:
A controlled comparison of text-only, vision-enabled, and gesture-enabled agents on identical deictic tasks.

BOUNDARY:
Machine perception of more context does not guarantee human-like situated understanding.

CITATION TRAIL:
Suchman 1987 → Put-That-There → requisite access → multimodal prompting.

TEST:
Use “put that there” under progressively richer machine access: text only, screenshot, cursor, gaze/pointing, interaction history; measure how explicit description changes.

HCI / multimodal agents.
