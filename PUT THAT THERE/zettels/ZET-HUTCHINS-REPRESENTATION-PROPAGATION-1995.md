TITLE:
A Cognitive Task Can Be Performed by Transformations Distributed Across People and Representational Media

SOURCE:
Edwin Hutchins - Cognition in the Wild - 1995. ([MIT Press Direct](https://direct.mit.edu/books/monograph/4892/Cognition-in-the-Wild?utm_source=chatgpt.com))

PASSAGE:
Hutchins analyzes ship navigation as a computational achievement distributed across social organization, representational media, historical practice, and coordinated activity rather than located wholly inside one navigator.

RESEARCH OBJECT:
The Yellow Circle pipeline as distributed cognition rather than one prompt translated by one mind.

LOCAL MOVE:
Gives a stronger account of GUI externalization and description migration: different pieces of requisite description may be maintained by different media and participants while the larger system accomplishes one computation.

SOURCE TERMS:
distributed cognition; navigation; computation; social organization; representation; cultural activity.

WHAT BECAME STRANGE:
Asking “where is the program?” may be badly posed when the operative computation is performed by propagation and transformation across several representational media.

QUESTION:
Should the unit of analysis for agentic programming be the model, or the model-plus-tools-plus-artifacts-plus-human coordination system?

DEEPER QUESTION:
Can prompt thickness be measured as a property of a distributed cognitive system rather than a text/model pair?

MECHANISM:
Representational states are transformed and propagated through coordinated people and artifacts, with different components carrying different portions of the computational burden.

FORMAL SHIFT:
ONE AGENT EXECUTES PROGRAM → COUPLED SYSTEM PERFORMS COMPUTATION THROUGH REPRESENTATIONAL PROPAGATION.

SOURCE FORMALISM:
Hutchins analyzes navigation as culturally and socially distributed cognition.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
YELLOW_CIRCLE_PIPELINE =
human distinction → prompt → model state → tool call → GUI state → renderer → visual artifact → human judgment,
with no requirement that one component contain the full operative description.

TENSION:
Distributed participation does not mean every element should be counted as cognitive in the same theoretical sense.

MISSING:
A criterion separating causal participation, informational mediation, and cognitive constitution.

BOUNDARY:
Do not infer that every software dependency is therefore literally part of a mind.

CITATION TRAIL:
Hutchins 1995 → GUI externalization → description migration → world-to-world.

TEST:
Remove individual representational supports from a Yellow Circle workflow and measure which distinctions humans or models must newly internalize to maintain performance.

Distributed cognition / HCI.
