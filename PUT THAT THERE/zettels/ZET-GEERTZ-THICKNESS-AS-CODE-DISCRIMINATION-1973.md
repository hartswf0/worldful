TITLE:
Thickness Is Not More Detail; It Is Enough Structure to Distinguish What Kind of Act Occurred

SOURCE:
Clifford Geertz - “Thick Description: Toward an Interpretive Theory of Culture” - 1973; drawing on Gilbert Ryle. ([Wikipedia](https://en.wikipedia.org/wiki/Thick_description?utm_source=chatgpt.com)) ([Canonical Link](https://monoskop.org/images/5/54/Geertz_Clifford_The_Interpretation_of_Cultures_Selected_Essays.pdf))

PASSAGE:
[QUOTE]
"Between the 'thin description' of what the winker is doing (rapidly contracting his right eyelid) and the 'thick description' of what he is doing (practicing a burlesque of a friend faking a wink to deceive an outsider into thinking a conspiracy is afoot), lies the entire object of ethnography: a stratified hierarchy of meaningful structures." — Clifford Geertz, The Interpretation of Cultures, Basic Books, pp. 6–10 (1973)

RESEARCH OBJECT:
A non-quantitative definition of thickness.

LOCAL MOVE:
Kills the interpretation of “thick prompt” as merely long or information-dense. Geertzian thickness is discriminative structure, not descriptive volume.

SOURCE TERMS:
thick description; twitch; wink; parody; code; interpretation; social action.

WHAT BECAME STRANGE:
A very long description can remain thin if it never supplies the distinction needed to tell which act is occurring.

QUESTION:
What is the prompting analogue of distinguishing wink from twitch?

DEEPER QUESTION:
Can prompt thickness be operationalized as the number of rival action interpretations eliminated rather than amount of context supplied?

MECHANISM:
Contextual relations partition observationally similar behavior into different socially intelligible acts.

FORMAL SHIFT:
THICKNESS = INFORMATION QUANTITY → THICKNESS = ACTION-DISCRIMINATING CONTEXT.

SOURCE FORMALISM:
Geertz uses Ryle’s example to distinguish levels of interpretation in ethnographic description.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
PROMPT_THICKNESS relative to action set A =
degree to which available context discriminates among rival next-actions in A.

TENSION:
Eliminating ambiguity is not always desirable; some language-games intentionally preserve several possible continuations.

MISSING:
A metric that handles useful ambiguity without equating thickness with determinacy.

BOUNDARY:
Geertz’s ethnographic thickness also concerns interpretive structures beyond immediate action selection.

CITATION TRAIL:
Ryle → Geertz 1973 → thick prompting → requisite description.

TEST:
Create multiple prompt contexts with equal token count but different ability to discriminate target actions; compare success independently of length.

PLATFORM:
Anthropology / prompt theory.
