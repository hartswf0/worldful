ZETTEL

ID:
ZET-ATTENTION-TAX-MUST-OUTRUN-COGNITIVE-DIMENSIONS

TITLE:
Attention Tax Is Redundant Unless It Explains Burden Migration Across a Coupled System

SOURCE:
Thomas R. G. Green and Alan F. Blackwell - Cognitive Dimensions of Information Artefacts: A Tutorial - 1998. ([Cambridge Computer Lab](https://www.cl.cam.ac.uk/~afb21/CognitiveDimensions/CDtutorial.pdf))

PASSAGE:
Cognitive Dimensions already analyzes whole notation-plus-environment systems through costs such as hidden dependencies, hard mental operations, diffuseness, viscosity, and premature commitment.

RESEARCH OBJECT:
The novelty test for attention tax.

LOCAL MOVE:
Opposes the graph’s own favored terminology. “Attention tax” should be retained only if it captures a mechanism not already covered by Cognitive Dimensions.

SOURCE TERMS:
cognitive dimensions; hard mental operations; visibility; hidden dependencies; diffuseness; premature commitment; notation; environment.

WHAT BECAME STRANGE:
Much of what we called language-specific attention cost already has a mature HCI vocabulary.

QUESTION:
What empirical prediction does attention tax make that a Cognitive Dimensions profile does not?

DEEPER QUESTION:
Is the new contribution not “cost” but the migration of requisite discriminatory work among human, model, interface, artifact, and environment?

MECHANISM:
Cognitive Dimensions characterizes usability tradeoffs in notational systems; the proposed attention-tax account adds participant-indexed allocation and transfer of requisite distinctions.

FORMAL SHIFT:
ATTENTION TAX = GENERIC DIFFICULTY → ATTENTION TAX = WHO MUST MAINTAIN WHICH ACTION-RELEVANT DISTINCTION, WHEN, AND AT WHAT TRANSFER BOUNDARY.

SOURCE FORMALISM:
Cognitive Dimensions profiles notation-environment systems rather than supplying a single scalar cognitive-load measure.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
ATTENTION_LEDGER(d,t) = participant responsible for keeping distinction d available at decision time t.

TENSION:
If the ledger does not yield distinct predictions, “attention tax” should be discarded or subordinated to Cognitive Dimensions.

MISSING:
Head-to-head empirical comparison.

BOUNDARY:
Transformer attention mechanisms must not be treated as identical to human selective attention.

CITATION TRAIL:
Cognitive Dimensions → attention tax → Ashby requisite access → description migration.

TEST:
For one invariant Yellow Circle task, shift a coordinate distinction successively from human memory to GUI display to model inference; hold output constant and test whether the proposed ledger predicts performance changes beyond standard dimension ratings.

PLATFORM:
HCI theory / conceptual opposition.
