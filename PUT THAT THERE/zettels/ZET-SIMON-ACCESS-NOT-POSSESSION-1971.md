TITLE:
Knowing Can Mean Having Timely Access Rather Than Carrying Information in Memory

SOURCE:
Herbert A. Simon - “Designing Organizations for an Information-Rich World” - 1971. ([Gwern](https://gwern.net/doc/design/1971-simon.pdf))

PASSAGE:
Simon shifts emphasis from possessing information to having access to stored information together with the skill required to use it.

RESEARCH OBJECT:
Progressive context disclosure and prompt thickness.

LOCAL MOVE:
Provides an older information-processing precedent for the graph’s distinction between context being present and context being retrievable when needed.

SOURCE TERMS:
knowing; access; storage; information; retrieval; skill; attention.

WHAT BECAME STRANGE:
A competent system need not carry every relevant distinction in its immediate working context if it can reliably locate and use that distinction before action requires it.

QUESTION:
Is knowing where to retrieve a distinction a compressed substitute for retaining the distinction itself?

DEEPER QUESTION:
What is the minimal indexical structure required for just-in-time operative description?

MECHANISM:
External stores plus reliable access procedures substitute for internal retention of detailed information.

FORMAL SHIFT:
KNOWING = CONTENT PRESENT → KNOWING = ACCESS PATH + USE COMPETENCE.

SOURCE FORMALISM:
Simon explicitly distinguishes possession of stored information from access and usable retrieval.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
REQUISITE_CONTEXT(t) includes information retrievable before irreversible action at t.

TENSION:
Retrieval introduces latency, search error, access failure, and selection costs.

MISSING:
A measure comparing prompt tokens saved against retrieval burden introduced.

BOUNDARY:
Access does not guarantee comprehension or correct application.

CITATION TRAIL:
Simon 1971 → Ashby requisite access → progressive disclosure → context engineering.

TEST:
Store Yellow Circle specifications externally and provide only increasingly compressed retrieval cues; measure the minimum cue needed for reliable recovery.

PLATFORM:
Information systems / agent context.
