ZET-SIMON-WORLD-AS-INFORMATION-STORE-1971

TITLE:
The World Can Carry Description That Need Not Be Represented in Advance

SOURCE:
Herbert A. Simon - “Designing Organizations for an Information-Rich World” - 1971. ([Gwern](https://gwern.net/doc/design/1971-simon.pdf))

PASSAGE:
Simon argues against the fantasy of thinking everything through before acting and calls the world itself the largest information store and laboratory from which consequences are learned.

RESEARCH OBJECT:
World-state as part of operative description.

LOCAL MOVE:
Strengthens the worldtexting and situated-action branches: not every consequential distinction must be predicted or encoded before action if reversible interaction can expose it afterward.

SOURCE TERMS:
world; information store; laboratory; consequences; experience; attention; action.

WHAT BECAME STRANGE:
A world-to-world system may rationally depend on the world to reveal distinctions after partial action rather than attempting complete anticipatory specification.

QUESTION:
When is it cheaper and safer to act, observe, and repair than to thicken the description beforehand?

DEEPER QUESTION:
Should requisite description depend on reversibility and cost of error rather than on the total set of potentially relevant disturbances?

MECHANISM:
Partial action reveals previously uncertain consequences; feedback supplies distinctions that were unavailable or expensive to anticipate.

FORMAL SHIFT:
SPECIFY EVERYTHING BEFORE ACTION → SPECIFY ENOUGH TO ACT SAFELY, THEN USE WORLD FEEDBACK AS DESCRIPTION.

SOURCE FORMALISM:
Simon contrasts exhaustive foresight with selective attention to consequential feedback from the world.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
UPFRONT_REQUISITE_DESCRIPTION decreases as:
reversibility increases,
feedback speed increases,
repair cost decreases.

TENSION:
For irreversible or high-cost actions, reliance on post-action information can be unacceptable.

MISSING:
A formal relation among description thickness, reversibility, feedback latency, and error cost.

BOUNDARY:
Simon’s argument is not a blanket endorsement of trial-and-error.

CITATION TRAIL:
Simon 1971 → Suchman situated action → thick prompt as situated resource → world-to-world.

TEST:
Compare Yellow Circle tasks where early wrong placement is freely reversible versus irrevocable; measure how much upfront location specification becomes rational in each case.

Design theory / cybernetics / agent control.
