TITLE:
Usability Testing Does Not Merely Discover Users; It Helps Construct the User the Machine Can Accommodate

SOURCE:
Steve Woolgar - “Configuring the User: The Case of Usability Trials” - 1990. ([Sage Journals](https://journals.sagepub.com/doi/10.1111/j.1467-954X.1990.tb03349.x?utm_source=chatgpt.com)) ([Canonical Link](https://doi.org/10.1111/j.1467-954X.1990.tb03349.x))

PASSAGE:
[QUOTE]
"Usability trials are not an objective discovery of the user's natural psychology. Rather, the usability laboratory is a site where the user is 'configured'—disciplined, constrained, and taught to become the kind of subject that the machine demands." — Steve Woolgar, Configuring the User: The Case of Usability Trials, The Sociological Review, 38(S1), pp. 58–99 (1990)

RESEARCH OBJECT:
The user as an effect of software interpretation and testing.

LOCAL MOVE:
Sharpens the persona critique: software production does not simply translate an already-existing human into a model; its representations and trials participate in deciding which human capacities count as legitimate use.

SOURCE TERMS:
configuring the user; usability trials; machine as text; textual boundary; interpretation.

WHAT BECAME STRANGE:
“User error” can function as evidence not only about a person’s competence but about the boundary the artifact draws between acceptable and unacceptable readers.

QUESTION:
When usability testing observes breakdown, which side is normally rewritten: interface, user model, instructions, or expectations about the user?

DEEPER QUESTION:
Can generative systems dynamically configure their users during interaction by rewarding certain ways of speaking and making others ineffective?

MECHANISM:
Design and testing establish an interpretive boundary between the capacities built into the machine and those assigned to its prospective user.

FORMAL SHIFT:
USER AS EXTERNAL REQUIREMENT → USER AS CO-PRODUCED ROLE OF THE ARTIFACT.

SOURCE FORMALISM:
Woolgar uses the metaphor of machine as text to analyze usability trials sociologically.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
CONFIGURED_USER =
the repertoire of conduct that the artifact recognizes as competent participation.

TENSION:
Configuration is not total determination; actual users can reinterpret, misuse, resist, and repurpose artifacts.

MISSING:

BOUNDARY:
