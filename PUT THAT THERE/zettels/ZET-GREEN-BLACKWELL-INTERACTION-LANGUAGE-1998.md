ZET-GREEN-BLACKWELL-INTERACTION-LANGUAGE-1998

TITLE:
Cognitive Dimensions Already Treats Interactive Use as an Interaction Language

SOURCE:
Thomas R. G. Green and Alan F. Blackwell - Cognitive Dimensions of Information Artefacts: A Tutorial - 1998. ([Cambridge Computer Lab](https://www.cl.cam.ac.uk/~afb21/CognitiveDimensions/CDtutorial.pdf))

PASSAGE:
The tutorial models interactive artefacts as controlled by an “interaction language” whose commands construct or modify information structures.

RESEARCH OBJECT:
The genealogy of GUI-as-language and attention tax.

LOCAL MOVE:
Moves “GUI as spatialized language” from metaphor toward an existing HCI formal vocabulary.

SOURCE TERMS:
interaction language; notation; information artefact; commands; persistence; environment.

WHAT BECAME STRANGE:
HCI already had a framework in which using an interactive device could be analyzed as uttering commands in a language without reducing interaction to textual syntax.

QUESTION:
What does “spatialized language” add beyond Green and Blackwell’s interaction-language account?

DEEPER QUESTION:
Can the Yellow Circle unify programming notation and direct manipulation using one cross-medium grammar of operative distinctions?

MECHANISM:
Interactive actions function as commands whose effects become persistent information structures.

FORMAL SHIFT:
GUI ≠ LANGUAGE → GUI HAS AN INTERACTION LANGUAGE WHOSE EXPRESSIONS MAY BE GESTURAL/SPATIAL.

SOURCE FORMALISM:
Cognitive Dimensions models notation plus environment and applies dimensions to the system as a whole.

OUR FORMALIZATION:
[OUR FORMALIZATION - NOT SOURCE SYNTAX]
GUI grammar distributes syntax across spatial placement, state, tool selection, gesture, and persistence.

TENSION:
“Attention tax” risks redescribing existing Cognitive Dimensions without adding explanatory power.

MISSING:
A direct comparison showing what attention tax predicts that Cognitive Dimensions does not.

BOUNDARY:
Cognitive Dimensions is explicitly a broad-brush usability framework, not a cognitive-process theory.

CITATION TRAIL:
Green and Blackwell 1998 → GUI language → attention tax → Yellow Circle.

TEST:
Score SVG, Logo, and Paint with canonical Cognitive Dimensions and with the proposed attention-distribution variables; retain new terminology only where it captures distinct variance.

PLATFORM:
HCI / notation studies.
