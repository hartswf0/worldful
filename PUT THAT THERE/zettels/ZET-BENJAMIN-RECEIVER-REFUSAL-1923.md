Benjamin Is a Bad Source for the Implied User Because He Explicitly Rejects the Receiver as the Basis of Art

SOURCE:
Walter Benjamin - “The Translator’s Task” / “The Task of the Translator.” ([Germanic Languages & Literatures](https://german.yale.edu/sites/default/files/benjamin_translators_task.pdf))

PASSAGE:
Benjamin rejects the ideal receiver as a useful theoretical foundation for understanding artworks.

RESEARCH OBJECT:
The genealogy of the implied-reader / implied-user branch.

LOCAL MOVE:
Kills a misleading edge in the current graph: Benjamin should ground mode-of-intention and transformation of the receiving language, not the implied-user claim.

SOURCE TERMS:
receiver; ideal receiver; theory of art; translation.

WHAT BECAME STRANGE:
The same essay useful for translation actively resists the audience-centered move we were trying to attach to it.

QUESTION:
Which sources should ground the software “implied user” instead?

DEEPER QUESTION:
Does software differ from Benjamin’s artwork precisely because a competent receiver can be constitutive of execution rather than incidental to the work’s existence?

MECHANISM:
Source correction by separating adjacent but incompatible theoretical claims.

BARTHES/BENJAMIN → IMPLIED USER becomes ISER / ECO / WOOLGAR / AKRICH → IMPLIED USER.
